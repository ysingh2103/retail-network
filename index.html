    Runbook · network or routing upgrade

    1. Back up current configs; note firmware versions
    2. Write the steps and a rollback plan; get change approval
    3. Schedule after hours; tell affected users and stores
    4. Make the change; test internet, Wi-Fi, payments and every VPN tunnel
    5. Monitor for 24 h; update diagrams and the IP plan

    Runbook · new store install

    1. Pre-stage firewall, switch and AP at HQ from the store template
    2. Activate the LTE SIM and test failover before shipping
    3. On site: patch, power on, check monitoring sees every device
    4. Test a real card payment, guest Wi-Fi isolation and the camera
    5. Add serials and IPs to inventory; label cables

    Checklist · evaluating new software

    • Supports SSO with Entra ID and enforces MFA
    • Where data is stored; SOC 2 or ISO 27001 report
    • Admin roles and least-privilege access
    • Access can be removed in offboarding
    • Doesn’t duplicate a tool we already pay for

    Rules of the template

    • NN is the store number. Store 01 is 10.1.x.x, Store 23 is 10.23.x.x. You can tell where a device is from its IP.
    • Gateway is always .1 on every VLAN, and it lives on the firewall.
    • POS is isolated. VLAN 10 can reach only Shopify and the payment processor (PCI DSS scope stays small).
    • Guest reaches the internet only. Client isolation on, no access to POS, Staff or the VPN.
    • Reservations for registers, printers and cameras so their IPs never change.
    • Two internet paths per store: cable (WAN1) and LTE (WAN2). SD-WAN on the firewall fails over automatically.
    • Every store has an IPsec tunnel to HQ for the file share and back-office apps. Payments never use the tunnel.
